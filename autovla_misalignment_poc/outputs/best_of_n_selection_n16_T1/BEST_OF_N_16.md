# 후보 다양성을 늘린 best-of-N: 배포 가능한 순이득

**답: 모델 자신의 후보 16개(T 1.0) 중 디코딩 확신도(평균 엔트로피, log-likelihood, 또는 둘의 순위 합)로 하나를 고르면, GT·외부 참조·교정 시점 없이 정상 장면을 해치지 않고 궤적 오차를 줄입니다.** 5 seed 합산 모집단 FDE는 0.58 → 0.40–0.42 m(−0.16 ~ −0.18 m, 세 규칙 모두 유의, 약 −30%)입니다. 실패율도 모든 규칙에서 1.51 → 약 1.1%(−0.4%p, 상대 −27%)로 줄지만 5 seed 합산 CI가 0을 겨우 포함합니다(자연 실패 장면 52개의 검정력 한계). 효과는 후보 다양성에 달려 있어 N ≤ 8이나 T 0.7에서는 작습니다.

> 이 보고서의 첫 판(3 seed)은 min_entropy의 모집단 실패율 감소를 −0.53%p [−0.89, −0.06]로 유의하다고 적었습니다. 추가 seed 3, 4를 합치면 −0.41%p [−0.81, +0.09]로 줄어 유의하지 않습니다. 아래 표는 모두 보존하되 결론은 5 seed 기준으로 고쳤습니다.

- 스크립트: `scripts/best_of_n_selection.py --n 16 --temperature 1.0`, `scripts/analyze_best_of_n.py` (규칙 정의는 [BEST_OF_N.md](../best_of_n_selection/BEST_OF_N.md))
- 실행: 2026-09-29, RTX 3080 Ti (`VLA_LOW_MEM=1`), torch 2.8.0+cu128, 후보 = T 0.01 1개(normal) + T 1.0 16개, seed 0, 349 장면(52 실패 + 297 정상, 실험 15와 동일).

## 해석

1. **다양성이 선택의 상한과 실제 이득을 함께 올립니다.** T 1.0, 16개로 실패 장면의 후보 간 거리가 1.43 → 2.18 m로 넓어지자 oracle 상한이 A− 28.8 → 11.5%로, 배포 가능한 최소 엔트로피 선택의 이득이 −11.5 → −26.9%p로 커졌습니다.
2. **모델의 확신도는 좋은 후보를 고르는 신호입니다.** 실험 15에서 엔트로피는 "안정화를 켤지" 정하는 장면 단위 trigger로는 쓸모가 없었지만, 같은 장면 안의 후보들 중 **덜 불확실하게 디코딩된 계획**을 고르는 데는 효과적입니다. 모델이 feedback에 휘말려 발산하는 후보는 디코딩 중 엔트로피가 높게 유지되는 것으로 보입니다.
3. **조건화(실험 12–16)가 실패한 이유를 피합니다.** 외부 motion을 context에 넣지 않으므로 모델이 틀린 참조를 따라가는 문제가 없고, 모든 후보가 모델 분포 안에 있어 정상 장면의 손해가 없습니다.
4. **비용**: 계획당 17배의 action 디코딩(prefix는 공유). 이 실험에서는 한 batch forward로 처리했습니다.

**다른 규칙 (3 seed 합산, 모집단)**: max_loglik −0.41%p [−0.82, +0.04] / FDE −0.18 m [−0.26, −0.09]; prev_consist −0.23%p [−1.18, +1.07] / FDE +0.09 m; medoid −0.18%p / FDE −0.08 m. N32 T1.3에서는 prev_consist가 정상 장면을 해칩니다(모집단 A− +2.02%p [+0.44, +3.98]).

- **min_entropy 선택은 4개 T 1.0 실행 모두에서 실패 장면 A−를 25–37%p 줄이고 모집단 FDE를 0.18–0.24 m 줄였습니다.** 모집단 실패율 감소는 방향이 4/4 일관되고, 3 seed 합산에서 유의합니다(−34% 상대).
- **다양성에는 적정점이 있습니다.** T 1.3에서는 후보가 정상 장면에서도 넓게 퍼져(0.47 → 1.21 m) 엔트로피·일관성 선택이 나쁜 후보를 고르기 시작합니다. max_loglik만 T 1.3에서도 안전합니다(모집단 FDE −0.18 m).
- N 16 → 32는 T 1.0에서 추가 이득이 뚜렷하지 않습니다(oracle 상한만 11.5 → 5.8%).

**앞쪽 step만으로 고를 수 있는가(계산 절약)**: 3 seed 기록에서 처음 K step의 평균 엔트로피로 선택하면 K = 2, 3, 4에서 실패 장면은 −6 ~ −26%p 줄지만 정상 장면을 해쳐 모집단 A−가 오히려 +0.6 ~ +1.1%p 늘어납니다. K = 6은 모집단 −0.16%p(유의하지 않음), K = 10(전체)에서만 −0.53%p로 유의합니다. 조기 가지치기로 디코딩을 줄일 수는 없습니다(첫 step은 모든 후보가 같은 분포라 K = 1은 선택이 일어나지 않음).

## 한계

- N, T 설정은 (16, 1.0), (32, 1.0), (32, 1.3)만 시험했습니다. 최적 T는 1.0–1.3 사이 어딘가일 수 있습니다.
- 3 seed 합산은 같은 장면의 반복이므로 장면 수(52 실패 / 297 정상)를 늘리지 않습니다.
- normal 행이 이 실행에서 정상 장면 1개를 A−로 냈습니다(batch 크기 17로 수치 경로가 달라진 탓). 모든 비교는 같은 batch 안의 쌍대 비교입니다.
- 모집단 추정은 실패 52 / 정상 297 표본의 가중 평균이라 불확실성이 큽니다(CI 참조).
- 실패 장면 정의(5090 자연 실행)와 이 실행의 GPU가 다릅니다.
