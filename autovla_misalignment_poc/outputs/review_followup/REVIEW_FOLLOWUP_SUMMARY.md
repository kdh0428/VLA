## 2. 원고와 요약 문서에 반영해야 할 정정

1. **p값 표기:** 단위 수준 McNemar p(예: 8e-42)는 쓰지 않는다. log 단위 sign-flip p를 쓰고, 독립 cluster 수를 함께 적는다. A−의 16 log는 13 drive이며, 이번 분석들은 drive 단위로 묶지 않았다.
2. **"Recent-GT 93%":** 분모는 GT-history 효과다. Normal 증폭률 대비로는 85%다. 또한 한 번 교정이 아니라 매 step 직전 위치를 교정하는 반복 개입이다.
3. **"Reverse":** 모델마다 다른 개입이다.
   - AutoVLA 실험 8: 별도 Normal 행의 embedding을 삽입한다.
   - Impromptu: 자기 오류를 다시 넣는다.
   - SpatialVLA closed loop: 정상 action을 실행하고 문맥만 교란한다.
   - 모델 간 비교표에서는 같은 개입처럼 쓰지 않는다.
4. **실험 11 "GT와 motion이 비슷한 token ≈ GT":** 동등성이 아니다. "작고 비유의한 차이"로 쓴다(장면 가중 기준 동등성 미성립).
5. **SpatialVLA 궤적 발산(m):** 실험 34·35의 값은 실행 명령의 누적값이다(실제 TCP 이동의 약 4배). 실제 위치 지표는 실험 35와 P1-D에만 있다.
6. **SpatialVLA move_near:** seed 0–119가 서로 다른 초기 상태 53개만 만든다. 실험 34·35의 move_near n은 과대 계산되어 CI가 실제보다 좁다.
7. **실험 35 결론 교체:** P1-D 결과로 다음처럼 바꾼다.
   - "재계획 간격이 문맥 효과의 궤적 지속을 키운다"는 문맥 예산을 고정해도 성립한다. 단 관측 갱신과 실행 노출이 함께 바뀌는 복합 설정 효과다.
   - P0-C의 "ensemble 감쇠"는 문맥 흡수가 아니라 실행 교란량 감소로 설명된다.
   - 실험 35의 r4e1 reverse −6.2%p는 새 units에서 재현되지 않았다(+1.3%p).
8. **P1-A A− 결과:** 등속 외삽 baseline과 구별되지 않는다. "문맥이 교란 방향 운동을 지속시킨다"까지만 쓰고, "등속 외삽보다 큰 자기증폭"은 쓰지 않는다. GT 없는 교정은 실패를 고치는 것이 아니라 문맥 일관성을 회복하는 것이다.

## 4. 수행하지 않았거나 한계가 남은 것

- **P2** (탐지·선택·closed-loop 확장): 계획서상 "주장 선택 후" 단계라 수행하지 않았다.
- **관측 갱신 vs history reset 분리:** 실행 가능한 정책 안에서는 분리할 수 없었다(P1-D 한계).
- **drive 단위 cluster:** P1-C를 빼면 사전 등록하지 않았다.
- **P1-C 실행 문제:** H8 단계가 메모리 부족으로 실패했다가 재실행됐다(수정 2). H8 없이 돌린 첫 분석 산출물은 따로 보존했다.
