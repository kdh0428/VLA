- 작성: 2026-10-08. 분석 규칙: `protocol.md` (계산 전 작성. **사전 등록이 아니다** — 실험 35 결과를 이미 본 뒤의 사후 재분석).
- 새 추론·GPU 없음. 원 자료·원 코드 수정 없음. 코드: `code/export_token_table.py`(CPU에서 processor만 로드), `code/p0c_analysis.py`.
- 표기: **[확인]** 기록·코드로 직접 확인한 사실, **[계산]** 이 재분석의 계산 결과, **[미확인]** 이 자료로 판별 불가, **[가설]** 해석 후보.
- 부호: `R−N` = reverse − natural, `F−C` = feedback − corrected. 성공률에서는 음수가 가설 방향(문맥 교란/교정 부재가 실패를 늘림). 궤적 편차는 두 조건 사이 TCP 거리(≥ 0)이며, 클수록 문맥만의 효과가 큼. DiD = (뒤 설정의 대비) − (앞 설정의 대비)이며, 같은 episode끼리 짝지음.
- 모든 설정 간 비교는 seed 0–39(task 2개 × 40 = 80 episode)에서 함. CI = task 층화 episode bootstrap 2,000회(seed 0, 한 episode의 모든 설정·조건을 함께 재추출). Holm(7)은 (지표, 대비 유형)마다 7개 DiD를 한 family로 묶은 보정, q는 전체 DiD 검정의 BH-FDR.

## 0. 자료 점검 [확인]

- 3,360 episode(seed 0–39 2,080 + seed 40–119 1,280)가 모두 80 step이다. 조기 종료가 없어 censoring 규칙의 조기 종료 항목은 적용되지 않았다.
- 교란 chunk 수는 r1 설정 16개, r2 8개, r4 4개로, 모든 episode에서 정확히 이 값이었다.
- 기록된 교란 token p는 `perturb_token(g, 0.3, opposite)` 재계산과 100% 일치했다. 조건별 문맥 token(F: p, C: g, R: 실행 g·문맥 p)도 100% 명세대로였다. p = g인 무효 교란은 0건이다.
- 실행 world_vector를 `preds`·`ages`와 ensemble 가중치로 다시 계산하면 기록값과의 최대 차이는 9×10⁻⁶(기록 반올림 수준)이다.

## 1. "ensemble 제거 +1.8 cm"의 정체 [확인 + 계산]

- **지표:** `analyze_protection.py` `pair_metrics`의 `mean_err`. 에피소드별로 t = 8–79 구간의 ‖p_feedback(t) − p_corrected(t)‖(실제 TCP 위치, cm)를 평균한 값이다.
- **비교:** `vs_r1e4["F_vs_C:mean_err"]` = 에피소드별 (r1e1 값 − r1e4 값), seed 0–39, n = 80. 즉 r1e1 대 r1e4의 F 대 C 위치 편차 차이이고, ensemble만 바뀐 비교다(r = 1 고정, e4 → e1).
- **값:** +1.757 cm (r1e1 7.27 cm, r1e4 5.51 cm). 원 코드 방식으로 CI [+0.66, +2.88]를 그대로 재현했다(이번 bootstrap으로는 [+0.64, +3.00]).
- **검정:** paired Wilcoxon p = 0.028. **다중 비교 보정은 적용되지 않았다.**
  - 원 코드는 Holm을 성공률 McNemar(C−F, N−R)에만 적용했다.
  - `vs_r1e4`의 궤적 대비(5설정 × 2대비 × 4지표 = 40개 검정)에는 보정이 없다.
- **보정을 적용하면:**
  - 원 비교 구조(축소 설정 5개 대 r1e4) 안에서 Holm을 적용하면 p = 0.142다.
  - 이번 고정축 family(7 DiD)에서도 Holm p = 0.142, 전체 BH q = 0.108이다.
  - sign-flip permutation으로는 p = 0.004다. 효과가 소수 episode에 몰려 있어서 검정 방식에 따라 p가 크게 달라진다.
- **task별:** coke +3.02 cm(p = 0.002), move_near +0.50 cm(p = 0.91). 거의 coke에서 나온 효과다.
- **주의: RESULTS.md에는 다른 "+1.8 cm"도 있다.**
  - "잦은 재계획" 답변의 "R 대 N 평균 오차 +1.8 cm, p = 1e-10"은 r4e1 − r1e4의 R 대 N mean_err다(합동 seed 0–119, n = 240; 재계산 +1.84 [+1.25, +2.46]).
  - 이 값은 r과 e가 동시에 바뀐 교차축 비교다.
  - 같은 비교를 seed 0–39로 하면 +1.41 cm [+0.53, +2.34], Wilcoxon p = 0.0014다.
- **RESULTS의 "r1e4 대비 차이" 표에 대해:**
  - r4e1 행만 n = 240이고 나머지 행은 n = 80이다.
  - 각 행 자체는 paired지만, p를 한 표에 나란히 두면 표본 크기 차이 때문에 r4e1만 유의해 보인다.
  - seed 0–39로 맞추면 F 대 C mean_err의 r4e1 − r1e4는 p = 0.10이고, 5설정 Holm 후에는 0.40이다.

**교란 token의 정밀도와 clipping**
- 요청 거리 0.3에 대해 98.8% 이상이 0.2–0.4 범위로 달성됐다. 목표점까지의 양자화 오차는 평균 0.044다.
- **방향 반전:** |v(g)| < 0.3이면 "opposite 0.3"의 목표점이 원점을 넘어가, 교란이 "감속"이 아니라 "역방향 이동"이 된다. 이런 chunk가 27–55%였고, 비율이 조건·설정마다 다르다(예: r1e1 C 27%, R 55%). **[확인]**
- **clip:** p token이 tokenizer의 [-1, 1] clip에 걸린 경우는 0%, g token은 0.3–2.6%였다. 정규화 경계(±1)에 닿은 p는 없었다.

**sticky gripper**
- window 안 sticky 시작은 episode당 0.4–1.3회다. natural과 첫 sticky 시점이 달라진 episode는 조건별로 40–81%다.
- 아래는 탐색적 지표다(계산 후 추가, protocol 부록 참조).
  - F−C의 window 안 sticky 시작 횟수 차이는 **r1e1에서 +0.46회/ep [0.33, 0.61]**이다. 다른 설정은 +0.06 – +0.16이다.
  - DiD는 r1e2 − r1e1 −0.30, r1e4 − r1e1 −0.31, r2e1 − r1e1 −0.36, r4e1 − r1e1 −0.38로, 모두 Holm < 0.005다.
  - R−N도 r1e1에서 +0.16(p = 0.003)이다.

**남는 교란 요인: r에 따른 dose 차이**
- e1 축에서 r1 → r2 → r4로 가면 세 가지가 동시에 바뀐다.
  - 교란 chunk 수: 16 → 8 → 4
  - 직접 실행 dose: 0.93 → 0.47 → 0.23 m
  - 문맥 translation 노출: 0 → 8 → 12
- 따라서 e1 축 DiD는 "재계획 간격 + 문맥 노출 증가 + 직접 dose 감소"의 복합 효과다.
  - F−C는 F와 C가 직접 dose를 공유하므로 그 부분은 상쇄된다. 그래도 교란 횟수 차이는 남는다.
  - R−N은 직접 dose가 0이지만, 문맥 교란 횟수(16/8/4)와 노출 경로(같은 step의 rot·grip 대 step 2–4 translation)가 함께 바뀐다.
- ensemble 축(r 고정)은 교란 chunk 수가 같다. 그러나 age-0 가중치(0.57 / 0.69 / 1.0)가 달라, 직접 실행 dose와 문맥 노출 구성이 함께 바뀐다.
- protocol대로 dose로 사후 정규화한 효과는 결론에 쓰지 않는다.

## 5. RESULTS.md 결론이 바뀌는가

1. **판정(Partial support)과 성공률 결론: 유지.**
   - 고정축 DiD 중 성공률에서 유의한 것은 없다.
   - 단, CI 폭(±11–20%p)을 함께 적어야 하고, "task 효과 없음"은 "검출 못함"으로 써야 한다.
2. **"ensemble 제거 +1.8 cm, p = 0.03": 보정 전 p로 표기해야 한다.**
   - Holm 후 p는 0.14이고, 거의 coke 한 task에서 나온 효과다.
   - "유의"가 아니라 "보정 전 p = 0.028(Holm 0.14)"로 써야 한다.
3. **"ensemble에 관한 부분은 지지되지 않는다 / 효과가 작고 일관되지 않다": 수정이 필요하다.**
   - 고정축으로 보면, E = 1 → 2가 r1·r2 두 축 모두에서 F−C 위치 편차를 약 1.8 cm(면적 −128) 줄였다(Holm 0.050 / 0.073; 최대 편차는 Holm < 0.03).
   - 방향은 "ensemble이 문맥만의 궤적 차이를 흡수한다"는 원 가설과 같다.
   - 반면 성공률 수준의 효과는 없고, E = 2 → 4는 무변화이며, R−N에서는 약하다.
   - 따라서 "궤적 수준에서 E1 → E2 감쇠의 약한 증거(보정 경계)"가 정확한 표현이다.
4. **"재계획 간격이 더 기여한다": 근거를 제한해야 한다.**
   - RESULTS의 가장 강한 증거는 r4e1 − r1e4(교차축, n = 240)다.
   - 깨끗한 재계획 축(e1 고정, n = 80)의 결과는 다음과 같다.
     - R−N의 최종·최대 편차와 command proxy는 r에 따라 유의하게 커졌다(Holm < 0.01).
     - R−N 면적은 Holm 0.18이고, R−N 재정렬은 n.s.다.
     - F−C 면적은 task별로 방향이 반대다.
   - e1 축은 교란 dose(16/8/4 chunk, 직접 dose 0.93/0.47/0.23 m)와 문맥 노출(0/8/12)이 함께 바뀐다.
   - "재계획과 ensemble 중 어느 쪽이 더 큰가"는 이 자료로 식별되지 않는다. 두 축이 서로 다른 대비(R−N 대 F−C)에 작용하고 dose도 다르기 때문이다. **[미확인]**
5. **기준 4 판정("충족, 재계획 축")은 r1e4를 비교 기준으로 한 교차축 결과다.** 고정축으로 바꾸면 "R−N 편차 크기 지표는 충족, 지속(재정렬) 지표는 미충족"으로 약해진다.

## 6. 가설 [가설]

- **r1e1에서 F−C 편차가 가장 큰 이유의 후보:**
  - r1e1에서는 매 step 실행되는 gripper·rotation이 문맥 교란을 받은 step-1 token 하나에서만 나오고, 평균되지 않는다.
  - 그래서 문맥 p가 gripper 닫힘 결정(sticky 시작)을 직접 바꾼다. F−C의 sticky 시작 차이가 r1e1에서만 +0.46회/ep다.
  - ensemble(E ≥ 2)은 translation 문맥 노출을 늘리면서도(0 → 5.0 / 6.8), gripper·rotation을 여러 chunk로 평균해 이 경로를 약하게 만드는 것으로 보인다.
  - 이 해석은 sticky 지표를 사후에 추가한 탐색 결과에 기반한다. 확인하려면 gripper·rotation token만 문맥 교란에서 분리하는 새 실행이 필요하다.
- "opposite 0.3" 교란의 27–55%는 방향 반전이다. 이 비율이 조건·설정마다 달라, 효과 크기의 일부가 섞였을 수 있다. **[미확인]**

## 7. P1-D와의 연결

- **문맥 예산 고정 설계:** r1 설정에서 t = 8, 12, 16, 20에 생성된 4개 chunk만 교란해, r4e1과 generation call 수를 맞춘다. 이때 r1e1의 실행 노출 차이는 따로 측정한다.
- **실행 섭동량 통제 설계:** episode당 직접 실행 dose(Σ w₀‖Δw‖)를 설정 간에 맞춘다(예: r4e1의 window 연장, 또는 r1 설정의 교란 chunk 수 축소). 달성 dose와 문맥 교란 횟수를 함께 보고한다.
- 두 설계 모두 원점을 넘는 "opposite" 교란(현재 27–55%)을 분리하거나, 크기 기준 교란으로 고정해야 한다.
- 성공률 상호작용을 1차 지표로 쓰려면, 현재 CI 폭(±11–20%p, n = 80)을 고려해 표본 크기를 먼저 정해야 한다.
