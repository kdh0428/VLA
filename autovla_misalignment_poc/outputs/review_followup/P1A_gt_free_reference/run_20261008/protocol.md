## 1. Question and hypotheses

Question (plan §6): Without GT information, does a local context change increase later generation deviation? Or do initial size plus cumulative coordinate composition explain the growth?

- **H1 (context-only effect)**: Change only the context token at t_p from r[t_p] to p and keep the output at r[t_p] (C1). The suffix local actions then move away from the reference more than in the unperturbed rollout (U).
- **H2 (beyond geometry)**: With output and context both perturbed (OC), the endpoint deviates from the reference more than the geometric baseline (Geo). Geo keeps the reference future local actions and composes only the first perturbation.
- **H3 (GT-free correction)**: A repeated sliding correction of the most recent context position with the model's own reference (OC_refR) reduces OC's endpoint deviation from the reference.
- **Interpretation rule (plan §11)**: If H1 and H2 hold and OC exceeds Geo, the effect is not explained by oracle information. If OC ≈ Geo, or OC ≈ CM (constant motion), interpret it as a motion prior / geometric consistency and shrink the self-reinforcement claim. A large effect is **not** a success criterion.

## 2. Design

### 2.1 Population
- The equal-distance set as in exps 6–11 and 32: 208 scenes (A− 52 / 16 logs, A+ 156 / 26 logs; 26 logs in total). [확인한 사실]
  - A−/A+ is a stratum defined from GT. It is inherited and only stratifies.
- Position t_p = t*, the first GT mismatch of the stored natural rollout. This position choice is GT-informed and inherited (limitation, see §8). No new log is used; P1-C is elsewhere.

### 2.2 Reference (fixed before any condition, no outcome label)
- Script: `scripts/review_followup/p1ab/p1_reference.py`.
- `r[:t*+1] = pred[:t*+1]` (stored natural tokens). `r[t*+1:]` is generated by the exp-7 harness.
  - Settings: B = 1, action rows, T = 0.01, seed key `"original"` (sha256(f"0:{token}:original:{k}")).
- The reference is greedy-equivalent at T = 0.01 with a fixed seed. It is **not selected by success**: every scene's single reference is used.
- It is written to `reference/references.jsonl`. Its sha256 is in `reference/manifest.json`, and P1-A/P1-B verify the sha256 before running.
- [계산한 결과, smoke] On 3 smoke scenes the reference equals the exp-7 Normal "original" raw token-for-token, which is the same numeric path.

### 2.3 Perturbations (units)
- **Family G (primary, GT-free).** Around r[t_p], in each of 8 direction sectors (45°, of disp[p] − disp[r[t_p]] in the token frame), take the token whose achieved distance is closest to **0.10 m per 0.5 s segment**.
  - Eligibility: |achieved − 0.10| ≤ **0.03 m**.
  - Ties are broken by angular error, then by token id.
  - Fixed before outcomes. Support (computed before any run): mean 7.0 sectors per scene, min 3, 84/208 scenes with all 8.
  - Common-support set = (scene, sector) pairs with an eligible token. Sensitivity: the 84 scenes with all 8 sectors.
  - Units ≈ 1,453.
- **Family E (secondary, linkage).** The existing equal-distance forced tokens (original + alternatives = 1,408 units).
  - These alternatives were distance-matched to the **GT** token, so their choice is GT-anchored. They are not GT-free.
  - E:original has p = r[t*] (no perturbation). It is excluded from contrasts and kept as a check row.
- Diagnostics recorded per unit (balance, not filters):
  - achieved distance, direction, sector, quantisation residual, Δheading of the token
  - natural-prediction and GT token frequencies
  - log p(p | prefix) and rank, log p(r[t_p] | prefix)
  - shape distance

### 2.4 Conditions (one batched forward per step, B = 10; common random numbers = one seed per scene and step for every row)

| row | output@t_p | context@t_p | context j > t_p (at step k, j = t_p+1..k−1) | arm |
|---|---|---|---|---|
| U | r | r | own | unperturbed |
| OC | p | p | own | output + context perturbed |
| O1 | p | r | own | output perturbed + reference context (one-shot) |
| C1 | r | p | own | reference output + context perturbed (one-shot) |
| OC_ref1 | p | p | j = t_p+1 ← r (fixed) | one-shot reference correction (GT-free win1) |
| OC_refR | p | p | j = k−1 ← r at every step | repeated sliding reference correction (GT-free Recent-GT) |
| OC_refH | p | p | all ← r | reference history (GT-free GT-history) |
| O_refH | p | r | all ← r | output perturbed + reference context, repeated |
| OC_gtR | p | p | j = k−1 ← GT | **GT arm**, comparator only |
| OC_gtH | p | p | all ← GT | **GT arm**, comparator only |

- Executed and decoded tokens = `pred[:t_p] + [output@t_p] + own samples`.
- Baselines computed with **no inference**, using the real decoder (`ActionTokenizer.rollout`), so translation and rotation are composed in the decoder's order:
  - **Geo** = `pred[:t_p] + [p] + r[t_p+1:]`.
  - **CM** = `pred[:t_p] + [p]×(10 − t_p)`: the perturbed local motion repeated, i.e. constant speed and yaw rate in the token frame.
- One-shot arms (O1, C1, OC_ref1) and repeated arms (OC_refR, OC_refH, O_refH, GT arms) are analysed as separate arms. They are never pooled.

### 2.5 Coordinate / prefix facts verified in the smoke trace [확인한 사실 + 계산한 결과, 4 units]
- AutoVLA tokens are relative motions chained from (0, 0, 0).
- Context tokens never enter the decoder.
- In every row:
  - the output prefix equals `pred[:t_p] + [output@t_p]`;
  - the decoder origin is (0, 0, 0);
  - the poses before or at t_p equal the in-process reference decode exactly (max abs err 0.0) for rows whose output@t_p = r.
- The prefix KV is unchanged (checksum) and cropped back to P after every step. The span is recomputed every step.
- **Consequence (structural).**
  - Generation depends only on the context, so **OC and C1 produce identical suffix tokens**, and **O1 and U produce identical suffix tokens** (4/4 smoke units).
  - O1 equals Geo token-for-token whenever U equals the reference.
  - In this model:
    - "output perturbed + reference context" **is** the geometric baseline;
    - "reference output + context perturbed" isolates the context effect;
    - OC − C1 is pure geometric composition of p vs r[t_p] under the same suffix.
  - The main run checks this per unit (`OC_suffix_equals_C1`, `O1_suffix_equals_U`). Any violation is reported, not silently dropped.

### 2.6 SECONDARY arm: GT-free fixed perturbation position (predeclared, lead decision 3)
- **t_p ∈ {1, 3}, the same for every scene.** Chosen without GT and without looking at any outcome.
  - 1 = the most common t\*; 3 is two steps later. Both leave ≥ 6 generated steps.
- Prefix = reference tokens r[:t_p] (the model's own, GT-free).
  - When t_p ≤ t\* these are the stored natural tokens.
  - When t_p > t\* they are the reference harness tokens.
- Family G at r[t_p] with the identical rule (0.10 ± 0.03 m, 8 sectors). Family name `GF1` / `GF3`. Same 10 rows, same baselines, same per-unit checks.
- Estimated units ≈ 2 × 1,450.
- Analysis: the 3 primary contrasts for GF1 and GF3 separately, A− first, then A+ and pooled. Unadjusted, reported as secondary. Never pooled with the t\* primary.
- Note: when t_p < t\*, U starts generating before t\*. U may then differ from the reference tokens r[t_p+1..t\*], which came from the stored HF-generate rollout. U − reference is reported as the noise floor.
- Script: `p1a_gt_free_reference.py --families G --fixed-positions 1,3` → `raw_fixedpos/`. Analysis output goes to `fixedpos/`.

## 3. Evaluation unit and weighting (per P0-B)
- Unit = (scene, perturbation). **Primary estimand: scene-weighted mean of the paired per-unit difference.** Units of a scene are averaged first.
- Clusters are logs: **16 logs for A−** (primary), 26 for A+.
- Sensitivities: unit-weighted and log-uniform weights, and leave-one-log-out.

## 4. Metrics (units fixed before outcomes)
- `dev_ref[i]`: L2 between condition pose i and reference pose i, in **metres**. Heading deviation is reported separately in **rad**. Translation and rotation are never combined.
- `dev9_ref`: endpoint deviation at pose 9 (5 s).
- `suffix_loc`: mean over k > t_p of ‖disp[o_k] − disp[r_k]‖ (m per 0.5 s segment, token-local frame).
- `suffix_yaw` (rad); `suffix_mismatch` = share of o_k ≠ r_k.
- `follow`: mean over k > t_p of ⟨disp[o_k] − disp[r_k], u⟩/d0, where u is the unit perturbation direction.
- Growth: `d0` = achieved perturbation size (m), the translational deviation at pose t_p.
  - `growth = dev9_ref / d0`, only if d0 ≥ **ε = 0.02 m**. Otherwise NaN; the count is reported.
  - Reported as log2 and median. h = 9 − t_p steps of 0.5 s.
- **Reference-relative**:
  - `severe_ref{2,3,4}` = dev9_ref > 2/3/4 m.
  - `refAm` = A− label of the existing P/R/A rule with the reference as target.
  - `ref_amp3` = refAm ∧ dev9_ref > 3 m.
- **GT-relative** (original `unit_metrics`):
  - amplification = A− ∧ FDE5 > 3 m;
  - amp2/amp4 at 2/4 m;
  - ADE5 and FDE5.
- Deviation over time: scene-weighted mean dev_ref per pose offset from t_p.
- Local suffix change and endpoint change are reported separately. So are reference-relative and GT-relative errors.

## 5. Contrasts and tests

**Primary family (Holm, m = 3)**: family G, A−, scene-weighted, log clusters.

| id | contrast | metric | H1 | equivalence margin (only if a null is claimed) |
|---|---|---|---|---|
| P1A-1 | C1 − U | suffix_loc | > 0 | ±0.02 m/segment |
| P1A-2 | OC − Geo | dev9_ref | > 0 | ±0.25 m |
| P1A-3 | OC_refR − OC | dev9_ref | < 0 | ±0.25 m |

- Tests:
  - log block bootstrap: multinomial log weights, B = 10,000, percentile 95% CI;
  - log-level **sign-flip** on per-log sums of scene means, exact over 2^16 sign patterns. This is a conditional test under symmetry, not exact randomization inference. Its p floor is 2/2^(informative logs);
  - cluster-t (df 15) as a sensitivity.
- Two-sided p. Holm-adjusted within the family.
- A null claim needs the 90% CI inside the margin (TOST); otherwise say "not detected, equivalence not established".
- **Secondary (unadjusted, labelled exploratory)** in `p1a_analyze.py: SECONDARY`:
  - O1 − Geo (expected 0), OC − CM, OC − O1, C1 − U endpoint/heading/mismatch;
  - one-shot vs repeated corrections;
  - GT arm vs reference arm;
  - severe_ref3, ref_amp3, GT amplification, FDE5, log2 growth.
  - The same set is run for family E, for A+, and pooled.
- Diagnostics (no test): perturbation balance (achieved distance, logp/rank, frequencies) by family and group.
- **Predeclared secondary sensitivities of the primary family** (family `P1A_sensitivity_*` in paired_effects.csv, unadjusted):
  - units with rank(p | prefix) ≤ 100, i.e. a plausible token (lead decision 2);
  - the 84 full-support scenes (all 8 sectors).
- Other sensitivities:
  - OOD flag per condition (mean Δ first-step entropy vs U > 1 nat, the original rule). Flagged conditions are reported, not dropped.

## 6. Exclusions and denominators
- No parsing step exists: sampling is restricted to the action rows and decoding always succeeds. parser_status = ok.
- Exclusions:
  - a scene/unit with a runtime error goes to `errors.jsonl` with its stage;
  - E:original (p = r) is excluded from contrasts;
  - growth is NaN when d0 < ε.
- Per-condition denominators are in `condition_summary.csv` (n_units / n_scenes / n_logs). Paired joins report `missing_pairs` and `dropped_nan`. The common paired set is used for every contrast. The no-exclusion version is the same table, because no outcome-based exclusion exists.

## 7. Stopping / termination
- One fixed run over all units. No interim look at outcomes and no adaptive extension.
- Abort and report without analysing outcomes if any of these fails:
  - (a) the reference sha256 check;
  - (b) output_prefix_locked / decoder_origin_zero / prefix_pose_err_zero < 100%;
  - (c) a cache check;
  - (d) more than 2% of scenes fail.
- If U ≠ reference tokens in more than 5% of units (numeric path B = 10 vs B = 1), report the rate. Analysis still uses the fixed reference, and U − reference is shown as the noise floor.
- GPU OOM (the 5090 is shared):
  - An OOM at model load (no record written) is retried automatically by `run_all_main.sh`, up to 3 times. The empty attempt dir is moved aside as `*.failed_attempt*`.
  - An OOM after records exist stops the launcher. The failed scenes are re-run once in a separate output dir with the same settings, then merged by unit_id. Both runs are recorded.

## 8. Known limitations (stated before results)
- t_p = t* and the A−/A+ strata come from GT. The **reference and family-G perturbations are GT-free**, but the selection of scene and position is not.
- Family-G tokens can be improbable under the model ([계산한 결과, smoke]: ranks 345 and 1,670). The rank ≤ 100 sensitivity addresses this; a plausibility-matched design would be a separate preregistration.
- bf16 with batch B = 10 numerics: every effect uses this run's own U, never another harness's Normal (P0-A F6).
