## 2. Primary (Holm, 2개) [계산]

### H1 — 재계획 축, 설계 A (문맥 예산 고정)

- 면적 DiD[R−N] r4e1 − r1e1 = **+213.8 cm·step**, 95% CI [+170.6, +255.2], 90% CI [+177.8, +247.9]. 이는 t = 8–79 평균 TCP 거리 약 +3.0 cm에 해당한다.
  - sign-flip p < 1e-4, Holm < 1e-4, Wilcoxon p < 1e-4.
- 구성 요소: R−N 면적은 r1e1 214.6 [188.6, 244.9], r4e1 428.5 [391.7, 466.7]이다.
- task별: move_near +227.3, coke +200.4. 두 task 모두 같은 방향이다.
- 의미 범위(100) 판정: 추정치와 95% CI 하한이 모두 100보다 크다. 사전 고정 문구는 다음과 같다.
  > "문맥 예산을 고정해도 재계획 간격이 문맥 효과의 궤적 지속을 키운다(복합 설정 효과)"
- 해석의 범위는 §6의 노출 측정과 §12의 한계를 따른다. 문맥 교란의 *횟수*는 같지만, 그 교란이 실행으로 새는 양은 r4e1에서 훨씬 크다. 그래서 이 효과는 "재계획 간격 + 관측 갱신·문맥 reset 빈도 + 실행 노출"의 복합 효과다.

### H2 — ensemble 축, 설계 B (직접 실행 dose 일치)

- 면적 DiD = r1e4(FD−CD) − r1e1(F−C) = **+20.7 cm·step**, 95% CI [−24.6, +68.0], 90% CI [−17.0, +58.9].
  - p = 0.385, Holm 0.385, Wilcoxon 0.248.
- 구성 요소: r1e4 FD−CD 330.1 [297.4, 367.4], r1e1 F−C 309.5 [274.7, 348.2].
- task별: move_near +12.0, coke +29.3.
- 판정:
  - Holm p ≥ 0.05이므로 검출되지 않았다.
  - 90% CI가 ±100 안이므로 **사전 정의한 의미 범위 안에서 등가**다.
  - 방향이 양수라 사전 문구의 "ensemble이 흡수"는 쓸 수 없다.
- 직접 실행 dose를 E = 1과 맞추면(§6: 0.230–0.231 m/ep), ensemble-4는 F−C 궤적 차이를 의미 있는 크기(≥ 100 cm·step)로 줄이지 않는다.

  - 전체 generation call 수는 72/36/18/72로 다르다. 고정한 것은 *교란된* call 수다.
- **E = 1 설정의 F/C 직접 실행 dose:** 0.228–0.231 m/ep로 일치한다. r1e4 F/C는 0.133 m/ep(= 0.574배)다.

  - rotation: 0.35 → 0.59 → 1.22 rad/ep
  - gripper: 0.56 → 1.05 → 2.15
  - 구조적 노출: 0 → 4 → 12
  - 따라서 H1은 "같은 문맥 교란이 더 많은 실행 노출로 이어지는 실행 설정"의 효과다. 노출당 효과로 정규화하지 않는다(protocol §2.2).
- **r1e1 R의 translation 노출이 0인 이유:** 문맥 교란은 같은 step의 rotation·gripper token에만 영향을 준다(0.35 rad, 0.56). 이 경로로도 R−N 면적 214.6이 생겼다.
- **반전(reversal) 비율 [확인]:** r4e1이 다른 설정(0.42–0.48)보다 낮다(0.32–0.37). 이는 주입 시점의 상태가 설정마다 달라서 생긴 불균형이다(§8).

## 10. 계획 §11 대응

- **"trajectory만 바뀌고 성공률은 불확실 → 생성 편차와 task outcome의 분리": 해당한다(더 강한 형태).**
  - 재계획 축은 같은 문맥 예산에서 문맥 기인 궤적 편차를 크게 바꿨다(H1 +214, T2 +140, T6 +18 step).
  - 같은 대비의 성공률 상호작용은 사전 정의한 ±10 %p 등가를 충족했다(S1–S4).
  - 실행된 섭동은 성공률을 낮췄다(§7.1, E = 1에서 −6 – −12 %p). 따라서 "task outcome이 둔감하다"가 아니다. **문맥에서 생긴 궤적 편차가 성공률로 번지지 않는다**는 분리다.
- **"실행 설정의 성공률 interaction까지 재현": 지지되지 않는다.**
  - S1–S4 모두 등가이고 비유의다.
  - 실험 35의 r4e1 R−N 성공 저하(−6.2 %p)도 이번 새 units에서는 재현되지 않았다(§11).
- **남는 범위:** 5–9 %p의 상호작용은 이 n으로 배제할 수 없다. "성공률 상호작용 없음"이 아니라 "±10 %p 이상의 상호작용은 없음(90% 신뢰)"으로 써야 한다.

## 12. 한계

1. **task 2개(move_near, pick_coke_can), 한 checkpoint.** 다른 과제나 접촉 단계가 주입 시점과 겹치는 과제로 일반화할 수 없다. 접촉 시점 가설(protocol §2.5)은 검정하지 않았다.
2. **재계획 축은 복합 실행 설정이다.** K를 바꾸면 관측 갱신 빈도, 문맥 reset 빈도, 실행 노출(translation 0 → 0.32 m/ep, rotation·gripper 약 3.5배)이 함께 바뀐다. H1은 "재계획만의 효과"가 아니다.
3. **관측 갱신과 history reset을 분리하지 못했다**(protocol §2.4). 실행 가능한 정책 안에서 "갱신만" 칸을 만들 수 없다. shadow decode의 counterfactual은 실행되지 않는 분석량이다.
4. **"opposite 0.3"의 방향 반전이 남아 있다.**
   - 주입 단위로 32–48%가 반전이다. coke 후반 주입은 최대 87%다.
   - 반전 비율이 설정 간에 불균형하다(r4e1이 낮음).
   - 사전 지정 반전 0회 하위집합은 n = 3–8로 정보가 없다(§8).
5. **설계 B의 FD/CD는 실험자가 주입한 offset이다.** 모델 token에서 나온 action이 아니다. dose는 맞췄지만 r1e4의 문맥 노출(1.70)은 남는다. 즉 dose와 노출을 동시에 고정한 설계는 없다.
6. **dose는 episode·주입 단위로 완벽히 맞지 않는다.** 주입 시점의 상태가 설정마다 달라 g, Δ, 반전 여부가 달라진다. 평균 Δ는 0.057–0.058 m로 비슷하다. dose로 사후 정규화한 효과는 쓰지 않았다.
7. **move_near episode-id 설계.**
   - 120 unit은 60 episode × 4 overlay = 240개 구성 중 실험 34/35가 쓴 53개를 뺀 187개에서 뽑았다(episode_id 58종, overlay당 30개).
   - 추론 범위는 이 유한한 구성 집합이다. 실험 34/35 구성과 겹치지 않도록 고른 것이므로 전체 240개에 대한 무작위 표본이 아니다.
   - coke는 seed 200–319의 연속 균등 초기 위치다.
8. **gen/null 기준선은 units 0–39에서만 측정했다.** 기본 발산의 설정 차이(gen DiD +54.7)가 H1의 일부를 설명할 수 있다(§7.3, 탐색).
9. **성공률 등가 범위(±10 %p)는 넓다.** 실험 35에서 관찰된 크기(약 6 %p)의 상호작용도 등가 범위 안에 들어간다.
10. **p 값의 해상도:** sign-flip 10,000회라서 p < 1e-4보다 작은 값은 구분하지 않는다.
