# 배포 조건: 교정 시점 없이 자연 디코딩에 이전 계획 안정화를 적용하면

**답: 실패 장면은 구하지만 정상 장면을 조금씩 망가뜨려, 실패가 드문 모집단 전체로는 손해입니다.** 이전 계획으로 처음 4 step의 조건화를 바꾸면 자연 실패 장면의 A−가 65.4 → 32.7%로 절반이 되지만, 무작위 정상 장면에서 A−가 0 → 2.0%, FDE가 +0.80 m 늘어 모집단 A− 비율 추정이 1.24 → 2.60%로 오릅니다. 모델 엔트로피로 켤 장면을 고르는 trigger도 모집단 실패율을 유의하게 개선하지 못했습니다(인과적 신호 기준 −0.18%p [−0.53, +0.19]).

- 스크립트: `scripts/natural_reference_stabilization.py` (GPU), `scripts/analyze_natural_reference_stabilization.py`, 장면 선택 `outputs/frame_index/natural_units.json`, 이전 frame `scripts/build_frame_scenes.py --units ... --no-future`
- 실행: 2026-09-29, **RTX 3080 Ti** (`VLA_LOW_MEM=1`, 다른 컨테이너가 GPU 0의 2.1 GB를 사용 중이어서 새 action embedding의 평균 초기화를 끔 — 체크포인트가 그 행을 덮어쓰므로 가중치 동일), torch 2.8.0+cu128, T = 0.01, seed 0, 52분. 349/352 장면(3개는 이전 frame 계획 실패).

## 1. 질문

실험 12–16은 모두 **oracle 교정 시점**(강제 perturbation의 첫 불일치 t*)에서 교정했습니다. 실제 시스템은 불일치가 언제, 일어났는지조차 모릅니다. 가장 단순한 배포형 정책 — 매 계획의 처음부터 이전 frame 계획으로 조건화를 교정 — 이 실제 실패율을 낮추는지 봅니다.

## 2. 설계

- **장면**: 자연 실패 장면 전부(arm N에서 P/R/A 5 s A−, 52개) + 나머지 2695개 중 무작위 300개(seed 0). 모집단 추정은 A− 52 / 정상 2695의 비율로 가중.
- **디코딩**: perturbation 없음. prompt + 저장된 natural stub의 prefix에서 10개 action을 생성. context 위치 0..w−1(`w2`, `w4`) 또는 전체(`all`)를 참조 토큰으로 두고, 실행 action은 모델 샘플. 모든 행을 한 batch로 같은 seed로 계산.
- **참조**: prev(0.5 s 전 frame 계획), consmed/consmean(0.5/1.0/1.5 s 전 세 계획의 합의), gt(oracle 상한).

**GPU 차이 주의**: 3080 Ti의 normal 행은 5090에서 저장된 자연 토큰을 정상 장면에서 77%, 실패 장면에서 23%만 재현했고, 실패 장면의 normal A− 비율은 100%가 아니라 65.4%입니다. 실패 장면은 모델이 확신하지 못하는 경계 장면이라 부동소수 차이만으로 결과가 바뀝니다. 모든 비교는 같은 실행 안의 쌍대 비교입니다.

## 4. 해석

1. **oracle 시점 없이도 실패 장면은 구해집니다.** 이전 계획으로 처음 4 step을 조건화하면 실패 장면의 A−가 절반(65 → 33%)이 되고 FDE가 1.9 m 줄어듭니다. 실험 12(oracle 시점, 증폭률 47 → 33%)와 같은 크기이며, 교정 시점을 알 필요가 없었습니다.
2. **하지만 정상 장면에서는 모델 자신이 참조보다 낫습니다.** 정상 장면에서 모델의 FDE는 0.47 m인데 이전 계획 참조는 이보다 부정확하고(실험 12: A+ ADE 0.95 m), 모델은 조건화된 motion을 따라가므로(실험 16) FDE가 +0.7–0.9 m 늘고 2% 정도가 A−로 넘어갑니다.
3. **실패가 드물기 때문에 손익이 역전됩니다.** 모집단에서 실패는 1.9%뿐이라, 정상 장면 2%의 손해가 실패 장면 절반의 구제를 넘어섭니다(모집단 A− 1.24 → 2.60%).
4. **엔트로피 trigger로도 해결되지 않습니다.** 실패 장면은 엔트로피가 높지만(AUROC 0.88), 그 신호는 교정할 위치보다 뒤의 토큰을 봐야 얻어집니다. 교정 전에 쓸 수 있는 첫 step 엔트로피는 AUROC 0.70이고, 이것으로 고른 정책의 이득은 유의하지 않습니다. 실패가 1.9%인 모집단에서 AUROC 0.7–0.9 탐지기는 정상 장면 오작동 비용을 이기지 못합니다.
5. **결론**: token feedback 안정화는 **기전 검증과 oracle 상한**으로는 강력하지만, 이 모델에서 비-oracle 참조로 배포하면 순이득이 없습니다. 더 정확한 참조(정상 장면에서도 모델보다 나은 motion) 또는 훨씬 정밀한 실패 탐지가 있어야 이득이 납니다.
