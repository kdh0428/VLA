# 여러 과거 계획의 motion 합의는 더 좋은 참조인가

**답: A−에서는 조금 더 낫지만 공짜가 아닙니다.** 0.5/1.0/1.5 s 전 계획 세 개의 codebook-medoid 합의(`consmed_all`)는 최신 계획 하나(`prev_all`)보다 A− 증폭을 7.1%p 더 줄이지만(35.1 → 27.9%, GT 효과의 27 → 44%), 정상 장면(A+)의 FDE를 +0.28 m 늘립니다. 오래된 계획일수록 참조 품질이 떨어지고 A+를 해칩니다. **최신 계획 하나가 여전히 안전한 기본값**이며, 합의는 A− 발산 억제를 더 원할 때 고르는 트레이드오프입니다.

- 스크립트: `scripts/reference_stabilization.py --sources gt,prev,prev2,prev3,consmed,consmean,consmedkin --windows w4,all`, `scripts/analyze_reference_stabilization.py`
- 실행: 2026-09-29, **RTX 3080 Ti** (5090은 실험 13 실행 중), torch 2.8.0+cu128, T = 0.01, seed 0, 27분. 207/208 장면(1 장면은 이전 frame 계획이 160토큰 안에 action을 내지 않아 제외), A− 365 / A+ 1037 단위.
- GPU가 달라 Normal 증폭률이 5090 실행(47.1%)과 약간 다릅니다(46.6%). 모든 비교는 같은 batch 안의 쌍대 비교이며, 기준 조건(normal, gt, prev)을 이 실행 안에 다시 포함했습니다.

## 1. 질문

실험 12에서 이전 frame 계획 참조의 효과는 참조↔GT motion 거리로 결정되었습니다(가까운 1/3: −30.6%p, 먼 1/3: +13.1%p). 비-oracle 참조의 품질을 높이는 가장 싼 방법은 여러 과거 계획을 합치는 것입니다.

## 2. 참조

토큰은 step별 국소 motion이므로, k step 전 frame에서 만든 계획을 k칸 밀면 현재 step에 대한 motion 참조가 됩니다(`prev{k}[j] = plan_{-k}[j+k]`).

| 참조 | 정의 |
|---|---|
| prev / prev2 / prev3 | 0.5 / 1.0 / 1.5 s 전 frame의 계획(각각 새 prompt, natural 경로), 1 / 2 / 3칸 이동 |
| consmed | step마다 {prev, prev2, prev3} 중 codebook 거리 합이 최소인 토큰(medoid) |
| consmean | step마다 세 토큰의 codebook motion 평균에 가장 가까운 학습된 토큰 |
| consmedkin | {prev, prev2, prev3, CTRA}의 medoid |

창: w4, all. 교정 시점(t*)은 oracle, 실행 action은 모델 샘플(실험 9–12와 같은 정의).

## 4. 해석

1. **최신성이 품질을 정합니다.** 1.0–1.5 s 전 계획은 motion이 낡아 A+를 해칩니다(증폭 +2–4%p, FDE +0.5–1.2 m). 실험 12의 "참조가 GT에서 멀면 해롭다"와 같은 현상입니다.
2. **합의는 A−의 큰 오류를 줄이고 A+의 작은 오차를 늘립니다.** medoid는 최신 계획이 크게 틀린 경우 다른 계획으로 대체해 A− 발산을 더 막지만, 최신 계획이 맞는 흔한 경우에는 더 낡은 motion을 섞어 정상 궤적을 약간 흐립니다. 평균 참조 품질이 거의 같은데 결과가 갈리는 것은, 합의가 **꼬리(큰 오차)를 줄이고 중앙값을 약간 올리기** 때문으로 보입니다.
3. **실용 권고**: 기본값은 최신 계획 하나(`prev_all`, A+ 무해). A− 발산 억제를 더 원하면 `consmed_all`(A− GT 효과 44%, A+ FDE +0.28 m 비용).

## 5. 한계

- 교정 시점(t*)은 oracle입니다.
- 3080 Ti 실행이라 5090 실행(실험 12)과 수치가 직접 호환되지 않습니다(Normal 46.6 vs 47.1%). 실험 12와의 비교는 같은 batch 안에 다시 넣은 기준 조건으로만 합니다.
- A− 52 장면, 단일 seed, T = 0.01.
- 합의 규칙은 두 가지(medoid, 평균 snap)만 시험했습니다. 가중치(최신 우선)나 모델 확신도를 쓰는 합의는 다루지 않았습니다.
