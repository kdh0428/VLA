# seed·온도 강건성: 이전 계획 안정화 효과(실험 12)는 우연인가

**답: 아닙니다.** 샘플링 seed(0, 1, 2)와 온도(T 0.01, 0.5)를 바꾼 6개 실행 모두에서, oracle 교정 시점의 이전 계획 참조(`prev_w4`)가 A− 증폭률을 45–48% → 31–33%로 줄였습니다(GT 교정 효과의 30–37%). A+에서는 해가 없거나 약간 개선됩니다. seed를 바꾸면 이전 frame 계획 자체도 새로 샘플링되므로, 참조 생성까지 포함한 강건성입니다.

- 스크립트: `scripts/reference_stabilization.py --sources gt,prev --windows w4,all --temperature T --seed S`
- 실행: 2026-09-29, RTX 5090, torch 2.8.0+cu128, 각 약 10분. T 0.01 seed 0은 실험 12의 실행입니다.

## 해석

- oracle 시점 안정화의 효과 크기(GT 효과의 약 1/3)는 seed·온도에 강건합니다. 실험 12의 log cluster CI 상한이 0에 가까웠던 것은 장면 간 변동 때문이며, 샘플링 변동은 효과를 흔들지 않습니다.
- T 0.5에서 Normal 증폭률이 약간 낮고(44.7–46.3%) A+ 증폭률이 약간 높습니다(4.6–5.3%). 샘플링 노이즈가 실패 장면에서는 갇힌 궤적을 가끔 벗어나게 하고, 정상 장면에서는 가끔 벗어나게 만듭니다.
- 이 강건성은 **oracle 교정 시점**에서의 결과입니다. 배포 조건(실험 15)에서는 같은 참조가 모집단 순이득을 내지 못했습니다.
