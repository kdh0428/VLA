## 1. Model, path, budget
- **Model.** Local `IPEC-COMMUNITY/spatialvla-4b-224-sft-fractal`: PaliGemma2 / Gemma 2 language model, SigLIP vision encoder, bf16, transformers 4.47.0 (`/root/VLA/spatialvla/site`). All file hashes are in `RUN_FINGERPRINT.json`.
- **Official path.** `predict_action` = `generate(**inputs.to(bf16), max_new_tokens=256, do_sample=False)`, with a hybrid cache.
- **Adapter path** (`scripts/svla_wc_core.py`). It reproduces `generate` step by step: one prompt prefill (official bidirectional prompt mask), then one action token per forward pass through a HybridCache of length P + 256. Forced conditioning tokens go through this causal path, never into the prompt. Batch size is 1.
- **Execution for observation collection.** The official SimplerEnv adapter: 224×224 INTER_AREA, prediction every control step, ensemble temperature −0.8 over the last 4 chunks, sticky gripper. The existing `PolicyState` / `svla_rollouts.worker` code is used. Interventions are **never** executed in the environment.
- **Budget.** At most 150 model-GPU minutes in total (the ledger is `run/gpu_ledger.json`: wall time of each process holding the model, including collection and failed attempts). Feasibility gets at most 30 minutes and the pilot at most 120. One RTX 5090 (physical GPU 1).

## 2. Interventions (actions numbered 1–4; zero-based token index = 3·(k−1)+field, with field 0 = translation, 1 = rotation, 2 = gripper)

| Arm | Conditioning a1 | Conditioning a2 | Generated |
| --- | --- | --- | --- |
| N | natural | natural | official `generate` (all 12 tokens) |
| R | natural (forced) | natural (forced) | a3, a4 (+ termination token) |
| O | donor a1 | natural | a3, a4 |
| L | natural | donor a2 | a3, a4 |
| OL | donor a1 | donor a2 | a3, a4 |

- Recorded output actions a1 and a2 are always the natural ones. Conditioning edits are never logged as executed.
- Each edit replaces a whole 3-token action (no special tokens).

## 3. Feasibility (validation panel)
- **Candidates.** `manifest/validation_candidates.json`: coke seeds 3000–3007 × generation calls 0, 4, 8 (24 candidates, ordered by seed and call). Their physical layouts are disjoint from the pilot.
- **Selection.** The first 12 with a valid natural output are used. Valid means: 12 action tokens of the correct type in each slot, with no EOS inside them. Short outputs are invalid and never zero-padded.
- **Checks.**
  - Official `generate` (with logits output) equals the collection-time `predict_action` output.
  - The adapter's natural 13 tokens equal the official tokens.
  - R reproduces a3–a4 raw tokens and the termination token.
  - Decoded actions are equal.
  - Max |logit difference| and argmax mismatches are recorded.
  - Replacement indices are correct, the emitted prefix is unchanged, a3–a4 type validity holds, and EOS behavior is native.
- **PASS** requires all of: 12 valid, adapter natural token equality 12/12, R token identity 12/12, decoded equality 12/12.
- **STOP otherwise.** Effect size and sign are never stop criteria.

## 4. Pilot (fixed now; frozen again before the pilot runs)
- **Panel** (`manifest/pilot_layouts.json`).
  - google_robot_pick_coke_can: new seeds 2000–2024 (25 distinct layouts; P1-D used seeds 0–119).
  - google_robot_move_near: all 10 SimplerEnv layouts (the lowest seed per layout fingerprint), reused from P1-D.
- **Observations.** Images before natural generation calls 0, 4 and 8 (= control steps 0, 4, 8), at most 105. An episode that ends earlier contributes fewer observations; observations are never duplicated.
- **Donors.**
  - Four sources per observation, from official `generate` with do_sample=True, temperature 0.7, top_p 1.0, top_k 0. Each uses an independent seed sha256("svla_wc_src:" + obs_id + ":" + j)[:4] and its own torch RNG state; greedy arms use no RNG.
  - The first **joint-valid** source in index order is used for O, L and OL. Joint-valid means: a1 and a2 token types are valid, both gripper tokens equal the natural ones, and d_O > 0 and d_L > 0.
  - If no source qualifies, the observation is SOURCE_MISSING, with no further sampling.
- **Response space.** u is the 6 normalized motion components (translation xyz from spherical bins; roll, pitch, yaw), decoded by the official action tokenizer **before unnormalization**. The gripper is reported separately.
- **Distances.**
  - D_i(X,Y) = (1/12) Σ_{t=3,4} Σ_{d=1..6} |u_X − u_Y|.
  - E_L = D(L,R), E_O = D(O,R), Δ = E_L − E_O.
  - d_O = mean_d |u_src(a1) − u_N(a1)|, d_L = mean_d |u_src(a2) − u_N(a2)|.
  - Matched means 0.8 ≤ d_L/d_O ≤ 1.25.
- **Primary analysis.** Δ over matched observations. Average within layout, then over layouts within a task (equal layout weights), then over the two tasks (equal task weights).
- **Interval.** Bootstrap with 10,000 resamples and seed 20261022: layouts resampled within each task (task fixed), observations of a layout kept together; 95% percentile interval.
- **NA rules.** If either task has no matched layout, the two-task estimate is NA. A task with ≤ 1 layout gets an NA interval.
- **Secondary analyses.**
  - Δ over all joint-valid observations.
  - Per-task results.
  - Responses at a3 and a4 separately.
  - Translation vs rotation components.
  - Gripper change rate.
  - Response vs donor distance.
  - D(OL,L) computed directly.
  - J = E_OL − E_O − E_L (signed, descriptive only).
- **Reporting.**
  - The interval is exploratory and conditional on these two tasks; it says nothing about a task population.
  - Denominators run from candidates to analyzed observations, with missing, invalid and no-op cases kept separate from zero responses.
  - L > O, L ≈ O and L < O are all reported as found.
- **Stops.** R mismatch on any pilot observation halts interpretation of that run until it is separated. The budget cap ends the run with partial results reported.

## Amendments
- **A1 (2026-10-22, before any valid feasibility result).** Feasibility attempt 1 (`run/feasibility_attempt1_obsid_bug`, 1.16 GPU-min) collected all 24 validation observations. However, the collector named them `val_pick_coke_can_*` while the manifest uses `val_coke_*`, so no candidate was matched and no check ran (0 records). Fix: the observation-id naming in `wc_run.py` now uses the manifest's short task names. Nothing else changed. Attempt 1 is kept, and its GPU time counts in the ledger.
- **A2 (2026-10-22, before any pilot output).** `analyze.py`: in the NA branch (a task without observations), the per-task means are now layout-weighted, consistent with the primary aggregation. Only the descriptive NA-case output is affected.
- **A3 (2026-10-22, after pilot attempt 1).**
  - **What happened.** Pilot attempt 1 (`run/pilot_attempt1_cache_reuse`, 6.94 GPU-min) failed R self-patch token identity in 4/105 observations. The protocol stop rule halted interpretation.
  - **Diagnosis** (`run/diag/`, logged in the ledger).
    - In the same process, the record-time official `generate` differed from the collection-time `predict_action` for 7/105 observations.
    - The cause is in transformers 4.47 `generate`: it keeps `self._cache` and reuses it whenever the stored HybridCache is at least as long as needed. After the longer move_near prompts, the coke calls therefore ran with a larger cache, which means different attention shapes and bf16 numerics.
    - In a fresh process (default kernels), all 7 affected observations plus 3 controls were consistent: 4 official calls identical and equal to collection, adapter equal to official, R identity 2/2 each.
    - Deterministic algorithms (`CUBLAS_WORKSPACE_CONFIG=:4096:8`) changed the kernels and the greedy tokens, so they were rejected.
    - Against the uncontaminated collection-time outputs, R and adapter-natural agreed in 102/105 attempt-1 observations. The remaining 3 were not separated further.
  - **Fix.** `svla_wc_core.py` deletes `generate`'s stored cache before every official call (collection and record time), so each call builds its own P + 256 cache, as the adapter does.
  - **Re-run.** Feasibility and the pilot are re-run in fresh directories with an unchanged protocol, manifests and analysis. Attempts 1–2 are kept and not interpreted.
  - **Disclosure.** The attempt-1 pilot summary was computed and viewed before the mismatch was traced; it is kept in `analysis_pilot_attempt1_NOT_INTERPRETED/`. No sample, donor or analysis definition changed after viewing it.
