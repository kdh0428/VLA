## 결과 해석과 남은 한계
- **해석 범위:** 다른 기반 모델 계열(SigLIP/Gemma 2)에서도 같은 호출 안에서 최근 행동을 편집했을 때의 반응이 이전 행동보다 크다는 점이, 사전 고정한 거리 매칭 규칙 아래 두 과제에서 관찰됐습니다. 다만 이것이 기반 모델의 인과 효과를 분리했다는 뜻은 아닙니다.
- **명령 수준 결과:** 실행하지 않은 명령 수준의 결과이고, 중간 행동을 자연값으로 고정한 조건입니다.
- **과제 범위:** 과제는 재사용된 시뮬레이터 과제 2개와 보조 과제 1개입니다(move_near layout 재사용).
- **매칭 coverage:** 64개 sample 안에서 거리 매칭 donor를 찾은 관측은 105개 중 69개입니다.
- **빌드 엔진:** 서버에 pdfLaTeX이 없어 tectonic(XeTeX 계열)으로 빌드했습니다. 저자 환경에서 8쪽 경계를 다시 확인해야 합니다.
