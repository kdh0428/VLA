# Model selection: within-call action-context candidates (2026-10-23 v04)

Scope: a source-based comparison only. The source survey and environment observations were supplied by the server agent; this CPU review did not re-fetch public repositories or re-inspect the remote server. No GPU was used, nothing was installed, and no weights were downloaded. Code was read from shallow clones in a scratchpad, from HF API metadata and from the local tree. **None of the four policies below is an experimental model of the paper.** All four are surveyed only.

Estimand under test: inside **one** model call that emits an action chunk token by token, the emitted early actions are held fixed. The decoder's conditioning copy of an earlier **time step** (the latest preceding step vs an older step) is swapped for a donor, and the change in the later continuation steps is measured.

Evidence tags: **L** = LOCAL (checked in code or on disk on this server). **P** = PUBLIC (checked in the official repo, paper or model card at the revision listed in `model_selection_sources.json`). **U** = UNVERIFIED.

## Notes

1. **WorldVLA repo and version.** The paper's URL `github.com/alibaba-damo-academy/WorldVLA` now 301-redirects to `alibaba-damo-academy/RynnVLA-002` (HEAD `e548ccc`, 2025-12-02). That repo's history was rewritten and no longer holds the original WorldVLA commits. In its `rynnvla-002/model/modeling_xllmx_chameleon.py`, every mask call is commented out and the code sets `attention_mask = None`. **The original code was read from the fork `Stars1233/WorldVLA@6a9af08`** (GitHub reports parent = RynnVLA-002). That fork holds upstream commits `128eb0a` (2025-06-23, CEN Jun) through `6a9af08`. The two versions must not be mixed: only the fork snapshot implements the paper-v1 masked model [P].
2. **WorldVLA vs OpenVLA/OFT decoding.** OpenVLA uses plain causal decoding of 7 within-step tokens. OFT uses no causal decoding at all: one bidirectional pass over zeroed slots. WorldVLA decodes causally, both across and within blocks, **except** for a mask that removes block-to-earlier-block attention among post-image action blocks. Among the four, only WorldVLA has emitted earlier time steps inside the call. Its own mask then cuts the channel this paper measures.
3. **pi0-FAST positions.** Early tokens carry low-frequency coefficients across all dims, and a token can span several (k, d) slots. A length-changing replacement shifts every later slot or triggers the zero-coefficient fallback. Positions must never be read as earlier or later physical actions.
4. **Earlier local note (`autovla_misalignment_poc/outputs/review_followup4/FEASIBILITY.md`, 2026-10-17).** Verdict: "pi0-FAST feasible with conditions; not feasible on this machine today". The reasons it gave:
   - disk (~3.1 GB free, about 20–25 GB needed);
   - JAX on the 5090 unverified (JAX #39336);
   - no PyTorch pi0-FAST in openpi;
   - an official `pi0_fast_libero` checkpoint exists, but its provenance and success rate are unverified;
   - cross-step action-context interventions are NA, so only within-chunk DCT-token interventions remain.
   
   It treated WorldVLA as a side note: the mask is applied in train and eval in the original code, RynnVLA-002 main disables it, and no matched masked/unmasked checkpoint pair exists. Today's source reading confirms both points at the same revisions. The OpenVLA B3 gate (`OPENVLA_GATE.md`) is NOT_RUN, and the weights were deleted in an earlier disk cleanup [L].
5. **Local search.** Under `/root/VLA`, the HF cache and the conda envs, there is **no** openpi, pi0, OFT, WorldVLA or RynnVLA code and no matching weights. Only the `autovla` env exists, and it has no JAX. The OpenVLA code at `/root/VLA/openvla/openvla` (`c8f03f4`, clean, identical to upstream HEAD) and `/root/VLA/openvla/openvla_hf` (byte-identical to the upstream `extern/hf/modeling_prismatic.py`) are present. Disk free on `/` is 2.4 GB [L].
