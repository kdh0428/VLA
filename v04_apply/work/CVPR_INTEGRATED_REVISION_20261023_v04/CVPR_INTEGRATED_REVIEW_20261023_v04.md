# CVPR 통합 결과 검토 — 2026-10-23 v04

## 판단

이번 후속 실험은 이전에 부족했던 **다른 기반 모델 계열에서의 거리 매칭 증거**를 보완했습니다. SpatialVLA를 단순한 부수 사례로만 두던 상태에서, 사전에 고정한 donor 선택 규칙 아래 두 과제에서 최신 위치 편집의 반응이 더 크다는 결과를 제시할 수 있게 됐습니다.

이제 중심 주장은 **세 정책에서의 위치별 조건부 반응과, 디코딩·실행·성공을 구분하는 검증 절차**로 정리할 수 있습니다. 새 방법이나 성능 향상을 제시한 연구로 바뀐 것은 아니므로, CVPR의 significance 우려가 완전히 해소됐다고 판단하지는 않습니다.

수치는 정규화 행동 거리의 차이입니다. 0.048을 성공률 4.8 pp로 읽으면 안 됩니다. 구간은 관측된 과제·배치에 조건부인 부트스트랩 구간이며, 새로운 과제 모집단에 대한 구간은 아닙니다.

후속 실험의 105관측 중 69개에서 64회 이내에 매칭 donor를 찾았습니다. 평균 donor 거리는 L=0.0541, O=0.0533이고 비율 허용 범위는 0.8–1.25입니다. 정확히 같은 크기·방향의 편집은 아닙니다. 같은 토큰 변화 유형을 갖는 48관측에서도 Δ≈0.048 [0.019, 0.079]였습니다. 직접 거리 D_S(OL,L)=0.021 [0.012, 0.030]이므로 이전 위치의 영향이 없다는 결론은 부적절합니다.

## v04에 직접 반영한 수정

1. **거리 정의.** SpatialVLA의 거리를 a3·a4의 여섯 운동 성분, 총 12개 정규화 성분의 평균 절대 차이로 명시했습니다. VLA-0의 30개 정수 성분 거리와 분리했습니다.
2. **Donor 의미.** 같은 sampled chunk의 대응 행동을 각 위치에 넣는다는 뜻을 명확히 했습니다. 동일한 행동 벡터를 a1·a2 양쪽에 넣는 설계가 아닙니다. gripper는 각 위치의 자연값을 유지합니다.
3. **조건부 효과.** O에서는 a2를 자연값에 고정합니다. 따라서 older→a2→suffix의 전체 전파가 아니라, 중간 행동을 고정한 위치별 반응입니다.
4. **서랍 표본 단위.** 15개 reset scenarios가 기록된 자세 기준 7개 군집을 공유한다는 점을 표·본문·그림에 반영했습니다. 지시문과 로봇 asset 이름을 제외한 기록 자세로 묶은 민감도 분석을 추가했습니다. 이는 로봇 asset의 물리 특성까지 동일하다고 가정한 분석은 아닙니다.
5. **사전 계획 표현.** 공개 등록의 근거가 없는 `pre-registered` 대신 `pre-specified`를 사용했습니다. 원래 프로토콜·잠금 기록은 변경하지 않았습니다.
6. **모델 선택 설명.** SpatialVLA를 모든 공개 모델 중 유일하다고 주장하지 않고, 조사한 후보 중 현재 개입에 맞는 시간 정렬 경로를 제공하는 모델로 설명했습니다. FAST의 autoregressive 성질을 인정하고 시간 비국소적 DCT/BPE 표현과 구분했습니다. WorldVLA 코드의 제3자 fork 출처를 명시했습니다.
7. **출판 그림·재현 자료.** v01/v02 같은 내부 단계 라벨을 discovery/follow-up으로 바꾸고, 서랍의 scenarios와 다른 과제의 layouts를 구분했습니다. 누락됐던 이전 raw ZIP을 동봉하고, 패키지 내부 경로만 사용하는 검증기·그림 스크립트를 추가했습니다.
8. **빌드·대상 연도.** 2026-10-23에 공식 CVPR 2027 지침과 배포 ZIP을 확인하고 공식 2027 스타일로 교체했습니다. 글꼴·여백을 별도로 조정하지 않았습니다. clean pdfLaTeX/BibTeX 빌드로 본문 8쪽 경계를 확인했습니다. LLM 사용 명세와 참고문헌은 9쪽부터, 보충자료 참고문헌은 19쪽부터입니다.
9. **필수 사용 명세.** 2027 지침이 요구하는 `LLM Usage Statement`를 본문과 참고문헌 사이에 추가했습니다. 확인된 ChatGPT/Codex 사용을 기술한 초안이므로, 저자는 다른 도구를 포함한 전체 연구 과정의 내역을 최종 확인해야 합니다. 공식 지침: https://cvpr.thecvf.com/Conferences/2027/AuthorGuidelines

## 검증 범위와 한계

- v03 ZIP의 376개 manifest 항목이 원본 해시와 일치했습니다. v04에서 기존 실험·snapshot·제공 검증기 237개 파일은 그대로 유지했습니다.
- NumPy/Pillow를 사용한 별도 구현으로 원시 토큰 디코딩, PNG 픽셀 해시, donor 순서·선택·거리, 고정된 emitted prefix, 17개 지표, 그림 CSV와 구간을 확인했습니다. 25,957개 검사를 통과했습니다.
- 기존 VLA-0 raw ZIP에서도 668개 검사를 현재 v04 원고에 대해 다시 통과했습니다. GPU 추론과 물리 시뮬레이션은 새로 실행하지 않았습니다.
- drawer는 R/adapter 토큰 검사를 44/44 통과했으나 collection-time natural 출력 비교가 없습니다. R logit 차이는 최대 0.5이며 토큰 변화는 없다고 기록돼 있습니다. 이를 bitwise logit parity로 서술하면 안 됩니다.
- 체크포인트 설정 snapshot은 기록 해시와 일치합니다. 실행 시점 해시가 없는 사후 코드 snapshot의 timestamp만으로 당시 바이트 동일성을 증명할 수는 없습니다.
- 대안 모델 조사 자료는 서버 에이전트가 기록한 revision과 출처를 검토한 것입니다. 이번 CPU 검토에서 공개 저장소나 원 서버를 새로 조회한 조사는 아닙니다.

## 지금 필요한 다음 작업

새 실험 요청을 여러 개로 나눠 다시 보낼 단계는 아닙니다. **v04 ZIP을 현재 원고 기준으로 사용하고, 코딩 에이전트에는 이 버전을 원 서버에 반영한 뒤 기존 결과·검증을 보존하도록 한 번에 전달하면 됩니다.** 별도 신규 GPU 실험은 이 수정본에 필요하지 않습니다. 제출 전 저자에게 남는 확인은 LLM 사용 명세의 완전성과 실제 제출 시스템의 등록 정보 등입니다.

이후 연구 범위를 더 키운다면 위치 반응을 활용하는 실제 개입 규칙과 충분한 과제·초기 상태에서의 실행 효용을 검증하는 방향이 필요합니다. 이는 현재 결과의 오류 수정과 구분되는 연구 확장입니다. 현재 원고는 검증된 범위로 마무리하고, 후속 방법 개발의 성과를 미리 주장하지 않는 편이 타당합니다.
