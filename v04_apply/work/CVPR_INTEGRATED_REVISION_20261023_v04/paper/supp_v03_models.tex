\section{Model Selection: Candidate Policies}
\label{sec:models}
A policy can serve the within-call estimand only if, inside one call, it emits several time steps autoregressively, so that later steps condition on the decoder's copy of earlier ones. Table~\ref{tab:models} summarizes code and model cards (revisions recorded in the package; L = checked locally, P = public source). The original WorldVLA implementation was inspected in the third-party fork \texttt{Stars1233/WorldVLA}, pinned to commit \texttt{6a9af08}.

FAST remains autoregressive: its DCT/BPE tokens encode coefficients over a whole chunk, so token positions do not identify individual physical time steps. Token-prefix or coefficient interventions require a different estimand; the representation does not imply an absence of action dependence.

\paragraph{Why SpatialVLA, and the separate implementation reasons.}
\begin{itemize}
\item \textbf{Scientific reason.} Among the examined candidates, SpatialVLA provides an accessible, time-aligned autoregressive interface outside Qwen2.5-VL for this contrast.
\item \textbf{Implementation reasons} (separate from the scientific reason). Its checkpoint and SimplerEnv setup were already installed and verified. The alternatives require additional checkpoint storage and, in some cases, different frameworks.
\item \textbf{WorldVLA.} It would provide only an architectural null control. The repository named in its paper now redirects to a successor in which the mask is disabled, so the masked version must be pinned to the original code.
\end{itemize}
